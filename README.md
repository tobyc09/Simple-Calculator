# C++ Calculator

A simple console-based calculator written in C++ while learning the language.

## How it works

The program asks the user to enter two numbers and an operator.

It then performs the selected calculation and displays the result.

Supported operations:

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)

The calculator continuously runs until the program is closed.

It also:

- Handles division by zero
- Uses separate functions for each mathematical operation
- Uses a `switch` statement to determine which operation to perform
- Waits for the user to press Enter before returning to the calculator
